# Design and Performance Evaluation of a CNN-Transformer Hybrid Model for Plant Disease Classification

## About the Project

This is a final-year academic major project that uses a CNN-Transformer hybrid deep learning approach for plant disease classification.

The model uses CNN-based feature extraction with MobileNetV2 and EfficientNetB0, followed by Transformer-based learning for classification.

## Technologies Used

- Python
- TensorFlow / Keras
- CNN
- Transformer
- MobileNetV2
- EfficientNetB0
- PlantVillage Dataset
- Google Colab

## Project Type

Final Year Academic Major Project
